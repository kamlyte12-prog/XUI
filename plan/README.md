# Agent context

This folder is the entry point for coding agents working on Xui. Start with [`agents.md`](agents.md), then open only the project references relevant to the change.

## Files

- [`README.md`](README.md) — this index and canonical-home policy.
- [`agents.md`](agents.md) — required invariants, regression checklist, working rules, and acceptance targets.
- [`conventions.md`](conventions.md) — repository-specific implementation patterns for code, widgets, styles, tests, and docs.
- [`plan.md`](plan.md) — canonical project status, risks, goals, roadmap, milestones, and open questions.
- [`architecture.md`](architecture.md) — agent-facing source map and invariants, linked to the user-facing architecture guide.
- [`tracking.md`](tracking.md) — canonical change history, decisions, and verification record.

The canonical roadmap and tracker live here. The root `plan.md` and `tracking.md` remain as compatibility pointers. The user-facing architecture guide stays in `doc/architecture.md`; `plan/architecture.md` contains only the agent source map and links there.
